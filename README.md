# Zelm 的信息资源库

> 探索 · 发现 · 创造 —— 一个属于 Zelm 的个人信息资源导航站。

## 简介

「Zelm 的信息资源库」是一个零依赖的个人导航站，用于收藏、分类和检索优质数字资源。页面采用暗色玻璃拟态设计，配以全屏星光背景与本地音乐播放器，兼具实用性、观赏性与个人风格。

**纯前端架构**：本站无任何后端服务器，全部数据（快捷网页、资源、设置、游戏开关）保存在**访问者自己的浏览器 `localStorage`** 中，可直接托管在任意静态平台（GitHub Pages / Cloudflare Pages / Vercel 静态等）。

## 功能特性

### 欢迎页面
- **单击进入**：点击「进入网站」按钮即可进入（纯前端 UX 门槛）
- **头像展示**：悬停放大效果，点击可查看大图并保存
- **粒子文字标题**："Welcome to Zelm's World" 粒子汇聚动画
- **WebGL 高光按钮**：进入按钮带鼠标跟随的高光描边特效
- **虚化背景图**：`assets/bg.jpg` 高斯模糊作为背景
- **语言与主题切换**：欢迎页底部可直接切换 9 种语言和深/浅色主题

### 快捷网页
- **内置 25+ 知名网站**：百度、知乎、微博、淘宝、京东、B站、抖音、网易云、GitHub、Wikipedia、DeepSeek、Claude、文心一言、千问、Qwerty Learner、重科统一认证、雨课堂等
- **按功能分类**：搜索、社交、视频、购物、工具、AI、校园、学习、娱乐等，分类按 A-Z 排序
- **网页按 A-Z 排序**：每个分类内的网页按名称拼音 A-Z 严格排序
- **置顶功能**：点击 📌 按钮可置顶常用网页，置顶卡片有青绿色边框和发光效果
- **每页 8 个 + 翻页**：超过 8 个自动分页，支持跳转到指定页
- **搜索与筛选**：关键词搜索 + 分类筛选
- **详情弹窗**：点击卡片打开详情弹窗，长链接自动省略
- **多语言支持**：网页名称和介绍支持 9 种语言切换

### 资源下载
- 卡片式展示与富详情弹窗（图标 / 分类 / 简介 / 详细介绍 / 添加日期 / 大小 / 标签）
- 支持关键词搜索与分类筛选
- 默认无内容，等待自行沉淀

### 小游戏（5 款）
- **记忆翻牌**：支持 4×4 和 5×5 两种模式
- **贪吃蛇**：方向键控制，开始按钮后才开始移动，速度适中
- **俄罗斯方块**：支持多种模式，窗口拉长一屏看完无需滑动
- **扫雷**：先选择难度（简单/中等/困难），不同难度对应不同棋盘大小，性能优化
- **跑酷**：Q版青绿色小猫模型，支持跳跃和下蹲（空格/↑ 跳，↓/左Ctrl 蹲），金币和道具系统
- 可在设置中单独开关每个游戏

### 音乐播放器
- **固定右侧中间**：不随页面滚动
- **5 首本地歌曲**：2 首 FLAC + 3 首 MP3
- **光盘旋转动画**：每首歌光盘颜色不同，播放时旋转
- **音量调节**：滑块控制音量
- **切歌弹窗**：点击光盘左侧弹出歌曲列表，可切换歌曲
- **自动播放设置**：可在设置中配置自动播放和默认音量

### 个人信息
- **个人简介**：基本信息介绍
- **教育背景**：重庆科技大学
- **擅长技术栈**：9 项按 A-Z 排序（Excel、机器学习、Power BI、Python、R语言、SPSS、SQL、数据分析、数据可视化）
- **MBTI 人格**：ENFJ 主人公，点击弹出完整人格介绍窗口

### 今日运势
- **固定右上角**：🔮 按钮
- **随机生成**：点击随机生成今日运势
- **完整内容**：综合星级、爱情、事业、财运、幸运色、幸运数字、寄语
- **多语言支持**：9 种语言切换

### 联系方式
- Gmail、微信、QQ、GitHub、抖音（Darling_Yu_02）等图标展示
- hover 显示详情，点击可跳转或复制
- QQ 跳转到官网

### 导航栏
- 11 项导航：首页、关于我、项目、博客、简历、证书、快捷网页、资源、小游戏、联系方式、设置
- 固定置顶，滚动定位

### 设置面板
- **9 种语言**：简体中文、繁体中文、英语、日语、韩语、法语、西班牙语、德语、俄语
- **主题**：深色 / 浅色两选项，默认深色
- **8 种配色方案**：极简青绿、莫兰迪、护眼、日落、海洋、紫罗兰、樱花、极光
- **字体大小**：小 / 中 / 大
- **背景效果**：粒子特效开关
- **背景音乐**：自动播放开关、默认音量
- **小游戏开关**：每个游戏可单独开关
- **数据管理**：重置快捷网页、重置资源、导出配置、导入配置
- **网页全屏**：⛶ 按钮，ESC 退出全屏
- **居中弹窗**：标题栏固定，内容区可滚动，隐藏滚动条

## 技术栈

- **纯前端**：HTML5 + CSS3 + 原生 JavaScript（ES6+）
- **无构建工具**：零依赖，直接打开即可运行
- **WebGL 特效**：使用 ogl 库实现按钮高光和文字扭曲特效
- **Canvas 动画**：粒子文字、背景星光、小游戏
- **本地存储**：localStorage 保存所有用户数据和设置

## 本地预览

纯前端站点，任意静态服务器即可运行，例如：

```bash
# Python（Windows 下也可直接双击 start-dev.bat）
python -m http.server 8000 --bind 127.0.0.1
# 然后浏览器打开 http://localhost:8000/
```

或直接双击仓库内的 **`start-dev.bat`**（自动定位目录、起服务、打开浏览器）。

> 说明：数据存于浏览器本地（localStorage），换设备 / 换浏览器 / 清缓存会丢失，各端不互通——这是纯前端版的取舍。
